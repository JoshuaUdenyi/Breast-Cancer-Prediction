A final-year BSc project: an end-to-end machine learning system that
predicts whether a breast tumor is **benign** or **malignant** from 30
cell-nucleus measurements, using a tuned **Random Forest Classifier**,
served through an interactive **Streamlit** web application.

## Project overview

Breast cancer diagnosis conventionally depends on a specialist visually
assessing digitized fine needle aspirate (FNA) images of a breast mass.
This project demonstrates how a supervised machine learning model,
trained on quantitative measurements extracted from such images, can
act as a decision-support tool that flags a tumor as benign or
malignant with an associated confidence score.

The project covers the complete applied ML lifecycle: data exploration,
preprocessing, model training with hyperparameter tuning, rigorous
evaluation and comparison against alternative algorithms, and
deployment as a polished, multipage web application.

## Objectives

1. Build and evaluate a Random Forest classifier for breast cancer diagnosis.
2. Compare Random Forest against Logistic Regression, Decision Tree, SVM, and KNN.
3. Package the trained model behind a usable, non-technical web interface.
4. Follow software engineering best practices (modular code, type hints, docstrings, PEP 8).
5. Produce a defense-ready, documented, deployable final-year project.

## Features

- Full exploratory data analysis (class balance, correlation heatmap, histograms, pair plots)
- Random Forest training with `GridSearchCV` hyperparameter tuning and 5-fold cross-validation
- Evaluation via accuracy, precision, recall, F1-score, ROC-AUC, confusion matrix, and classification report
- Model comparison against Logistic Regression, Decision Tree, SVM, and KNN with justification for the final choice
- Multipage Streamlit app: **Home**, **Prediction**, **About Model**, **Help**
- Grouped, tooltip-annotated input form for all 30 features, with medically plausible range validation
- Single-record and batch (CSV upload) prediction modes
- Color-coded result banner (🟢 benign / 🔴 malignant) with a Plotly confidence gauge
- Downloadable single-prediction report (.txt) and batch results (.csv)
- Session-based prediction history table
- Custom CSS styling, responsive layout, sidebar navigation
- Modular architecture separating training, inference, utilities, and UI

## Dataset

**Wisconsin Diagnostic Breast Cancer (WDBC)**, loaded directly from
scikit-learn — no external download required:

```python
from sklearn.datasets import load_breast_cancer
```

- 569 samples
- 30 numerical features (10 base measurements × mean / standard error / worst)
- Binary target: malignant (0) / benign (1)
- Source: UCI Machine Learning Repository

## Usage

### 1. Train the model

The repository already includes a pre-trained `model.pkl`. To retrain
from scratch:

```bash
python utils/train_model.py
```

This regenerates `model.pkl`, `feature_names.pkl`, `metrics.pkl`,
`metrics.json`, and all EDA/evaluation plots in `images/`.

Alternatively, open `notebooks/train_model.ipynb` in Google Colab and
run all cells, then download the three `.pkl` files into the project
root.

### 2. Run the web application

```bash
streamlit run app.py
```

Then open the local URL Streamlit prints (typically
`http://localhost:8501`) in your browser. Use the sidebar to navigate
between **Home**, **Prediction**, **About Model**, and **Help**.

## Model performance

The tuned Random Forest achieved the following on a held-out 20% test
set (see `metrics.json` / the **About Model** page for the exact
numbers from the most recent training run):

| Metric | Score |
|---|---|
| Accuracy | 95.6% |
| Precision | 95.9% |
| Recall | 97.2% |
| F1-score | 96.6% |
| ROC-AUC | 99.3% |

Best hyperparameters are selected automatically via `GridSearchCV`
over `n_estimators`, `max_depth`, `min_samples_split`, and
`min_samples_leaf`, and are recorded in `metrics.json` for
reproducibility.

## Deployment

### GitHub

```bash
git init
git add .
git commit -m "Initial commit: Breast Cancer Prediction System"
git branch -M main
git remote add origin https://github.com/<your-username>/Breast-Cancer-Prediction.git
git push -u origin main
```

> **Note:** `model.pkl` is small enough (a few MB) to commit directly.
> If it grows large, consider Git LFS.

### Streamlit Community Cloud

1. Push the repository to GitHub (see above).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **New app**, select your repository, branch (`main`), and set the main file path to `app.py`.
4. Click **Deploy**. Streamlit Cloud will install `requirements.txt` automatically and launch the app.
5. Once deployed, share the generated public URL.
